# AGENT 06

# Sprint 7 — Assessment Player & Modul EPDS

## Project

Monitoring Ibu Nifas

---

# Tujuan

Membangun Assessment Player sebagai antarmuka generik untuk mengerjakan assessment serta mengimplementasikan assessment pertama, yaitu Edinburgh Postnatal Depression Scale (EPDS).

Assessment Player harus dapat digunakan kembali oleh assessment lain tanpa perubahan struktur aplikasi.

Sprint ini menghasilkan alur lengkap mulai dari Mother membuka Assignment EPDS hingga mengirimkan hasil assessment untuk direview oleh Bidan.

---

- Assessment Engine
- Dashboard Mother

# Assessment Player

Assessment Player merupakan UI generik.

Assessment Player bertanggung jawab terhadap:

- Menampilkan informasi assessment
- Menampilkan pertanyaan
- Menampilkan progress
- Validasi jawaban
- Navigasi antar pertanyaan
- Ringkasan jawaban
- Submit assessment

Assessment Player tidak boleh mengetahui algoritma penilaian EPDS.

---

# Assignment

Mother hanya dapat membuka Assignment yang diberikan oleh sistem.

Mother tidak dapat:

- membuat Assignment
- menghapus Assignment
- mengubah jadwal Assignment

Assignment menjadi pintu masuk menuju Assessment Player.

---

# EPDS Module

Implementasikan assessment pertama.

Nama:

Edinburgh Postnatal Depression Scale (EPDS)

Gunakan pertanyaan resmi EPDS.

Jangan mengubah:

- urutan pertanyaan
- isi pertanyaan
- pilihan jawaban

---

# Assessment Manifest

Setiap assessment wajib memiliki manifest.

Minimal berisi:

- code
- title
- description
- version
- totalQuestions
- reviewerLevel1
- reviewerLevel2

Assessment Player membaca informasi assessment melalui Manifest.

Jangan melakukan hardcode.

---

# Question

EPDS memiliki 10 pertanyaan.

Semua pertanyaan wajib dijawab.

Gunakan tipe pertanyaan:

Radio Button

---

# Validation

Pastikan:

- seluruh pertanyaan dijawab
- jawaban valid
- Mother hanya dapat mengisi Assignment miliknya sendiri

Jika terdapat jawaban yang belum diisi.

Tampilkan pesan validasi yang jelas.

---

# Progress

Tampilkan progress.

Contoh.

3 dari 10 pertanyaan

Gunakan Progress Bar sederhana.

---

# Navigation

Mother dapat:

- Pertanyaan Sebelumnya
- Pertanyaan Berikutnya

Pada pertanyaan terakhir.

Tampilkan tombol:

Lihat Ringkasan

---

# Ringkasan Jawaban

Sebelum submit.

Tampilkan seluruh jawaban.

Mother masih dapat kembali memperbaiki jawaban.

---

# Submit

Saat Mother menekan Submit.

Assessment dikirim ke Assessment Engine.

Status Assessment berubah menjadi:

SUBMITTED

Mother tidak dapat mengubah jawaban setelah submit.

---

# Scoring

Perhitungan skor dilakukan pada:

modules/epds/score.ts

Assessment Player tidak boleh menghitung skor.

---

# Interpretation

Interpretasi skor dibuat pada:

modules/epds/interpreter.ts

Interpretasi belum ditampilkan kepada Mother.

Interpretasi digunakan pada sprint berikutnya untuk proses review.

# Assessment Assignment

Assessment tidak dibuat secara langsung oleh Mother.

Assessment selalu diawali dengan Assignment yang dibuat oleh sistem.

Flow:

System

↓

Create Assignment

↓

Mother membuka Assignment

↓

Mother mengisi Assessment

↓

Submit

↓

Assessment dibuat

↓

Review Workflow

↓

Completed

Assignment bertanggung jawab terhadap:

- Jenis assessment
- Jadwal
- Due date
- Status tugas
- Progress Mother

Assessment bertanggung jawab terhadap:

- Jawaban
- Nilai
- Review
- Riwayat
